A pure-stdlib Python program that draws one newspaper front page summing up Wednesday 18 November 2026: the Dow sinking and gold crashing below $3,800 as Fed minutes point to more hikes, Xi and Putin meeting in Shenzhen ahead of the first three-way summit with Trump, Iran's drones targeting a US base in Kuwait, Peltola winning Alaska to give Democrats a 56-44 Senate majority, Nvidia's $115.8bn quarter, Israel's first Gaza ground move since the 2025 truce, and the Quad meeting in Manila. It carries its own 5x7 bitmap font and PNG encoder, draws flat-colour pictograms for every story, and writes a deterministic 1024x1024 image — two runs produce byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
